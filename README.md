# NetSuite SuiteScript 2.1 — Automation Library

A collection of real-world SuiteScript 2.1 scripts for NetSuite ERP automation. Built and maintained by a **4X NetSuite Certified Consultant** with 18+ years of ERP experience.

These scripts solve common business problems in Order-to-Cash (O2C), Procure-to-Pay (P2P), inventory management, and financial workflows.

---

## 📁 Scripts Included

| # | Script | Type | What It Does |
|---|--------|------|--------------|
| 1 | [Auto Email on Invoice](./1-auto-email-on-invoice/) | User Event | Sends a branded PDF invoice email to the customer automatically when an invoice is approved |
| 2 | [PO Approval Workflow](./2-po-approval-workflow/) | SuiteFlow + UE | Routes Purchase Orders for approval based on amount thresholds |
| 3 | [Overdue Invoice Alert](./3-overdue-invoice-alert/) | Scheduled | Daily job that emails AR team a summary of overdue invoices |
| 4 | [Item Reorder Alert](./4-item-reorder-alert/) | Scheduled | Alerts purchasing when inventory drops below reorder point |
| 5 | [Customer Credit Check](./5-customer-credit-check/) | User Event | Blocks Sales Order save if customer is over their credit limit |
